# English with Vova

Готовая первая версия веб-приложения для GitHub Pages.

## Публикация
1. Создайте новый публичный репозиторий на GitHub, например `english-with-vova`.
2. Загрузите файл `index.html` в корень репозитория.
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите Source: Deploy from a branch.
5. Branch: `main`, Folder: `/ (root)`, затем Save.
6. После публикации GitHub Pages покажет адрес сайта.

## Использование
Откройте сайт в Chrome/Samsung Internet в верхней части Split Screen, а ChatGPT Voice — в нижней.
